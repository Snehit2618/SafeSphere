Disaster Awareness and Assistance

Overview
This project is a web-based application designed to educate users on disaster preparedness and provide real-time assistance during emergencies. It is built using HTML, CSS, and JavaScript and features an interactive chatbot for guidance and an emergency button that helps users find the nearest hospitals in their surroundings.

Features
Educational Content: Provides information on what to do during various types of disasters (earthquakes, floods, fires, etc.).
Chatbot Assistance: A chatbot that answers disaster-related queries and provides safety guidelines.
Emergency Button: Redirects users to a page that uses location services to find the nearest hospitals.
Responsive Design: Works on desktops, tablets, and mobile devices.

Technologies Used
Frontend: HTML, CSS, JavaScript
Chatbot Integration: JavaScript-based chatbot logic
Geolocation API: Used to find nearby hospitals

## Usage
1. **Explore Disaster Guidelines**: Read through disaster preparedness tips available on the homepage.
2. **Ask the Chatbot**: Use the chatbot feature to get real-time answers to common disaster-related questions.
3. **Emergency Button**: Click the emergency button to be redirected to a page that locates the nearest hospitals using the Geolocation API.
